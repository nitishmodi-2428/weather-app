# 🌦️ Weather App

A responsive weather application built with **HTML, CSS, and JavaScript** that displays real-time weather information for cities around the world using the OpenWeatherMap API.

## ✨ Features

- 🌍 Search for weather by city name
- 🌡️ Display current temperature in Celsius (°C)
- 💧 Show humidity levels
- 💨 Display wind speed in km/h
- 🌤️ Dynamic weather icons based on weather conditions
- ⚠️ Error message for invalid city names
- 📱 Responsive design for desktop and mobile devices
- 🎨 Modern gradient UI with hover effects

## 🛠️ Technologies Used

- **HTML5** — Structure of the application
- **CSS3** — Styling, gradients, animations, and responsive layout
- **JavaScript** — API requests and dynamic UI updates
- **OpenWeatherMap API** — Real-time weather data

## 🔒 Security Note

The API key used in client-side JavaScript is visible to anyone who visits the website. Avoid committing private credentials to GitHub. For public deployments, consider using a backend to protect the key or applying the API provider's available key restrictions.
